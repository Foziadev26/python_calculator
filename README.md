# Python Calculator

A simple command-line calculator built with Python as a beginner practice project.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulus (`%`)
- Power operation (`**`)
- Decimal number support using `float()`
- Division by zero handling
- Invalid number handling using `try-except`
- Invalid operator handling

## Technologies Used

- Python
- VS Code
- Git and GitHub

## How to Run

1. Install Python on your computer.
2. Clone this repository or download the project files.
3. Open the project folder in VS Code.
4. Open the terminal and run:

   ```bash
   python calculator.py
   ```

## Example

```text
Please enter number1: 10
Please enter number2: 3
Please enter a operator (+,-,*,/,%) +
10.0 + 3.0 = 13.0
```
